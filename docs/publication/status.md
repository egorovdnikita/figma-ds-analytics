# Статус первой публикации

13 ноября 2026. **В Figma Community не отправлено.**

Подготовлено:

- версия 0.1.0, changelog, описание только реализованных возможностей;
- иконка 128 × 128 и обложка 1920 × 1080 на вымышленных данных;
- актуальная политика приватности, ссылка поддержки GitHub Issues;
- production build, TypeScript, ESLint и 150 тестов проходят; HTML 499,5 КБ.

Осталось в Figma Desktop:

1. Открыть Plugins → Development → Manage plugins in development.
2. Зарегистрировать плагин в аккаунте, получить выданный Figma ID вместо
   временного `figma-ds-analytics-dev` и записать его в manifest.json.
3. Заполнить форму публикации материалами из этой папки, загрузить иконку
   `docs/assets/plugin-icon.png`, проверить данные и отправить на ревью.
4. Зафиксировать выданный URL и фактический статус In review / Published.

Через доступное UI-управление меню Figma читается, но переход к форме
разработчика не подтверждён. Попросили пользователя открыть это окно вручную;
настройки аккаунта, 2FA и отправка на ревью пока не проверены.
Фиктивный ID не заменяется случайным числом. Публикация не считается выполненной
по успешной локальной сборке или по нажатию непроверенной команды меню.
