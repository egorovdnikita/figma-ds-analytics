# Токены Box UI: синхронизация и исключения

Источник истины — актуальные исходники `~/Projects/box-ui`, только чтение.
Версия и SHA-256 входов генератора/трёх CSS записаны в
`src/ui/vendor/box-ui/tokens-source.json`. Иконки исключены из синхронизации.

```sh
npm run check:box-ui
npm run sync:box-ui
npm run check:tokens
```

`check:box-ui` заново собирает токены и сравнивает входы и результат, ничего не
записывая в проект. `sync:box-ui` обновляет только три CSS и manifest.
Обе команды копируют `tokens/figma` и `packages/tokens/scripts` во временную
директорию, запускают там штатный генератор Box UI и удаляют копию. Никаких
clone, установки зависимостей, запуска скриптов или записи внутри Box UI.
Другой путь: `BOX_UI_DIR=/путь/к/box-ui npm run check:box-ui`.
Сравниваются сами входы, поэтому незакоммиченные изменения токенов тоже видны;
новый коммит Box UI без изменений входов не требует обновления вендора.

`check:tokens` работает без соседнего репозитория и сети: проверяет SHA-256 CSS,
входит в сборку UI и CI. `npm test` дополнительно проверяет ссылки на переменные
и отсутствие циклов в цепочках для light/dark × четырёх статусов с используемыми
модами deep/medium/inter/desktop/solid/default. Это статическая проверка CSS,
а не браузерный движок и не проверка всех возможных мод Box UI.

При обновлении сначала выполнить `check:box-ui`, изучить diff исходников,
синхронизировать и проверить вид обеих тем. SHA-256 не доказывает визуальную
совместимость обновления. Не добавлять fallback со случайным похожим значением.
Сборка не подключает `adaptive.css`: iframe остаётся desktop независимо от ширины;
темой управляет `theme.ts` на корневом элементе. Статусы используют штатный
`data-box-control` вместе с `data-status`.

## Соответствия

- Цвета интерфейса — semantic surface/accent/status/interaction из Box UI.
  `panel` и `panel-card` — документированные перестановки page/raised между темами
  для существующего оформления. Категорийные `detail-*` — локальные роли,
  ссылаются на палитру, не на статусы: violet/blue/orange/pink 600 → 450 в dark,
  green 700 → 450. Выбранный сегмент использует постоянные white/black;
  выбранный фильтр в dark — achromatic-light. Эти роли сохранены.
- Отступы Tailwind: ключ × 4 → `--spacing-N`; размеры элементов — `--size-N`.
  Только точные значения шкалы 2–96. Ноль, проценты, auto, viewport и flex/grid
  являются геометрией, а не заменой токена.
- Радиусы xs/sm/md/lg/card → rounding xs/s/m/l/xl, pill → `--rounding-full`.
  Специальные радиусы списка 32/24 и миниатюры 4/2 остаются примитивами.
- Размер/интерлиньяж текста — responsive `--type-*`; medium/semibold — семантика,
  normal — `--font-weight-regular`. Шрифт интерфейса — `--font-family-body`.
- Теней в интерфейсе плагина нет. Цветовые прозрачности берутся готовыми
  семантическими токенами, модификаторы вида `bg-accent/25` не используются.

| KPI h4                    | leading-none: 24px                                   | h4: 32px                     | Сохранён локальный множитель 1                             |

Не заменять их ближайшими числами без отдельной задачи на изменение дизайна.

## Локальные значения без семантического аналога

- Маскот: кадр 200/160px, высота 128/96px, положение 0.5575 кадра — геометрия
  исходного Lottie. Кадры и высота 128 оформлены локальными токенами, 96 — size.
  Сам Lottie — неизменяемый иллюстративный ресурс, не палитра интерфейса.
- Размеры gauge/подсказки 240px, sparkline 120px, описания 360px, карточки 128px
  — локальные размеры; в шкале Box UI до 96px таких размеров нет.
- Графики: viewBox, координаты дуги/столбиков, stroke 16/1.5/2, точка r=2.5 —
  геометрия данных в SVG, а не размеры контролов. Пропорции и вычисления сохранены.
- Рамка 1px, выделение/focus 2px, focus offset 1px, disabled opacity 0.5 —
  локальные токены: отдельных шкал border-width/focus/opacity в Box UI нет.
  Alpha-48 — цветовая ступень, она не заменяет прозрачность всего контрола.
- Анимации 180/280/700ms, reduced motion 0.01ms; ease-out и
  cubic-bezier(0.22,1,0.36,1), стандартные transition-colors 150ms и width 300ms —
  локальная анимационная спецификация. В Box UI нет motion-токенов.
- Breakpoint max-height 600px — условие компактного маскота, не mobile-мода.
  Полное скрытие/показ (opacity 0/1), прозрачный фон, currentColor, none и нулевые
  отступы остаются техническими константами. `@font-face font-weight: 400` —
  дескриптор шрифта, `var()` в нём недопустим.
- Внешняя оболочка `scripts/create-preview.mjs` — служебный стенд с собственной
  геометрией и палитрой; она не входит в UI плагина и в синхронизацию с Box UI.

Иконки и их размеры не менялись. Локальные токены не подменяют отсутствующие
имена Box UI и лежат отдельно от неизменённого результата генератора.
