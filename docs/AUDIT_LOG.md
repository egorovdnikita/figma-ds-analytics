## 2026-11-12 · Повторный аудит и правки

База: `53c44dc`, проверен diff до `6ec1ca5` и текущие изменения. Названия и описания проверены во всех актуальных файлах, включая GitHub About, README, паспорт, инструкции, privacy, package metadata, HTML title и manifest. Исторические отчёты и решения не переписывались.

### Воспроизведение и исправлено

- **P1 · Все инстансы пропадали из отчёта.** Страница с одним верхним INSTANCE: traversal выставлял `insideInstance=true` уже на самом инстансе; условие `!context.insideInstance` в `src/main/index.ts` отбрасывало его. Добавлен отдельный признак верхнего инстанса. Тесты: `test/scanner/traversal.test.ts`, полный обработчик скана в `test/scanner/scan.test.ts`; вложенный инстанс не задваивается.
- **P1 · Фильтр «без связи» терял реальные слои.** `getMainComponentAsync()` возвращает null: счётчик unknown увеличивался, но `countMasters` пропускал запись; список был пуст и переход к слою невозможен. Теперь сохраняются имя и место инстанса с origin unknown. Проверка полного скана подтверждает счётчик и nodeId для перехода.
- **P1 · Impact завышал число слоёв.** Один variable id привязан к двум свойствам одной ноды: два `usage.add` давали nodes=2 и повторное место вместо одного слоя. Индекс дедуплицирует пару nodeId/variableId; регрессия в `test/analysis/usage.test.ts`.
- **Единое имя.** Актуальные названия приведены к `figma-ds-analytics`; README описывает текущую аналитику и правильный пункт запуска. About: `TypeScript, React, Vite, Tailwind CSS, esbuild, Vitest` (проверено после изменения через gh).

### Проверки

- TypeScript, ESLint, Vitest (142 tests / 16 files), production build и бюджет UI (303 KB / 500 KB); форматирование проверяется по отслеживаемым файлам. Общий `npm run verify` останавливается на форматировании исходного незакоммиченного `AGENTS.md`, который оставлен без изменений.
- `npm audit --omit=dev`: 0 уязвимостей. В runtime-коде не обнаружены сетевые отправки, eval или вставка HTML из данных; networkAccess остаётся none. Проверка исходников и diff на типичные секреты и контакты совпадений не дала.
- Глазами по скриншотам Playwright: **7 экранов/состояний**. Desktop 1920×1080: сводка (верх и низ), компоненты. Окно плагина 480×640: карточка компонента, коллекции, список токенов, карточка токена, запуск скана. Повторные снимки после таймаутов получены и просмотрены. Дополнительно проверены DOM и клики.
- `dist/` пересобран; браузер перезагружен, title проверен. Переустановка и реальный запуск в Figma не выполнялись; UI проверялся с вымышленным отчётом из штатного промо-сценария.

### Сознательно не трогаем

- Все исключения предыдущего аудита остаются в силе; новые правила и редизайн не добавлялись.
- Исходный локальный `AGENTS.md` и скрытое skip-worktree изменение manifest (`permissions: teamlibrary`) сохранены. В коммит manifest включено только имя; локальное разрешение не присваивается этому аудиту.
