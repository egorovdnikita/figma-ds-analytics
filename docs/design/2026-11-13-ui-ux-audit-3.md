## Новые находки сверху вниз

### U10. Незакоммиченная правка роняет плагин — критический

**Сейчас:** `App.tsx:161` и `App.tsx:348` вызывают `withCount`, но импорта
в `App.tsx` нет. `npm run typecheck`:
`App.tsx(161,16): error TS2304: Cannot find name 'withCount'`.
Vite собирает без проверки типов, поэтому `npm run build` проходит, а в Figma
при старте проверки и при показе отчёта — `ReferenceError`, белое окно.

**Решение:** в `App.tsx` добавить
`import { withCount } from '../shared/plural';`. Перед коммитом — `npm run verify`.

### U11. Тёмная тема, детали: плашка с числами не видна — средний

**Сейчас:** `Facts` (642 копии · 18%, 3 412 слоёв · 6 страниц) красится
`bg-panel-card`. В тёмной теме это `--surface-base-fill-raised`, RGB 23, —
тот же цвет, что у листа деталей, RGB 23. Плашки нет, числа висят в воздухе.
В светлой теме плашка серая на белом листе, а список мест под ней в тёмной
теме, наоборот, темнее листа (RGB 10). Внутри листа две разные логики.

**Решение:** `Facts` в листе — `--surface-base-fill-page` в обеих темах:
светлая — серая на белом (как сейчас), тёмная — RGB 10 на RGB 23, как список
мест под ней. Остальное использование `panel-card` (кнопки, дорожка) на полотне
не менять.

### U12. «Используется наполовину» при 76% — средний

**Сейчас:** `advice.ts:130` выдаёт «Дизайн-система используется наполовину»
для всего диапазона 50–79%. Под числом 76% текст спорит с числом.

**Решение:** формулировка без количества:
«Часть копий собрана мимо библиотеки». Порог 80% и тон `warn` не трогать.

### U13. Первый замер: пустые места почти не видны — низкий

**Сейчас:** пунктирные места под будущие замеры обведены
`--surface-base-border-default`. В светлой теме едва заметны, в тёмной —
почти сливаются с фоном. Мысль «здесь появятся следующие замеры» не считывается.

**Решение:** обводка `--surface-base-border-strong` (как `border-line-strong`),
толщину 1,5 и пунктир 4/4 сохранить.
