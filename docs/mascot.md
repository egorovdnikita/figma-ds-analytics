# Маскот

В интерфейсе используется Cat из установленного в Agent Pulse пака Agent Pals.
Клипы Idle и Thinking воспроизводятся без перерисовки и изменения таймингов
лёгким SVG-плеером Lottie. Три петли Idle сменяются одной петлёй Thinking.
Это декоративная последовательность, без функций агента, реакций на курсор
и привязки к состоянию сканирования.

Платный пак остаётся локальным, как в Agent Pulse. Vite встраивает выбранные
клипы в автономный HTML из `~/Library/Application Support/AgentPulse/Skins/AgentPals`.
Для другой машины можно задать `AGENT_PALS_DIR`. В git исходники пака и `dist`
не включаются. Без установленного пака маскот не показывается; остальные
функции плагина и сборка работают.

При `prefers-reduced-motion` показывается первый кадр. В скрытой вкладке
воспроизведение приостанавливается. Плеер и анимации работают без сети.
